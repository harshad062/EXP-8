# TourMate - Local Tourism Guide (ReactJS)

Ex No: 8 | Modern User Interface Design Using ReactJS | URK24CS1071

## Run locally
```
npm install
npm run dev
```
Open the URL shown in the terminal (usually http://localhost:5173).

## Build / deploy (GitHub Pages)
1. In `vite.config.js` set `base: "/<your-repo-name>/"`.
2. `npm run build` and publish the `dist` folder (e.g. with the `gh-pages` package).

## Pages (React Router)
/ Home | /about | /contact | /register (validated form) | /login (responsive) | /students (dynamic state)
